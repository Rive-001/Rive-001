## Projects

### [PIE - Perturbation is Everything](https://github.com/ArcInstitute/pie)

PIE is a perturbation effect prediction ML model that generalizes to an combinatorial space of perturbation datasets, unseen contexts and unseen perturbations. It leverages prior curated biological knowledge from public databases such as NCBI, Cellosaurus, DepMap and STRING to represent the biological system of contexts and perturbations. It also simplifies the learning task, predicting differential expression membership and direction for measured genes. Checkout the paper here: https://doi.org/10.64898/2026.10.02.756297
